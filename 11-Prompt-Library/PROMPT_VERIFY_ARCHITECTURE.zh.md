# 提示词库：架构与代码对齐验证

**用途：** 用于在 Phase 6 (Verification) 阶段，将实现的代码 (C#/F#) 交给 LLM (Gemini 或 ChatGPT) 审核，确保其完全符合我们在 Phase 3 (Architecture) 中定义的五层架构设计。

---

### 提示词模板 (Prompt Template)

复制以下内容，并将代码粘贴在最下方：

```text
你是一个资深的软件架构师。我们的项目遵循一个严格的「五层弹性架构 Agent 循环」，旨在最大化 LLM 输出的可靠性。

这五层架构包含：
第 1 层：核心 Agent 循环 (ReAct 模式，包含 max_iterations 控制)
第 2 层：输出恢复 (处理 finish_reason="length" 或空响应)
第 3 层：自我纠正 (处理不存在的工具或无效 JSON)
第 4 层：提供商故障转移 (处理 429 和 5xx 错误)
第 5 层：质量门控 (对话历史压缩与校验)

请审查以下我用 [填入 C# 或 F#] 实现的核心循环代码。
你的任务是：
1. 评估代码中是否完整实现了这 5 层逻辑？如果有缺失，请明确指出是哪一层。
2. 代码的异常处理或重试逻辑是否有遗漏的边界情况？
3. 针对不符合架构设计的部分，提供重构建议的代码片段。

以下是我的源代码：

<在此处粘贴你的实现代码>
```
